## 概要

htmx は、HTML を拡張してインタラクティブなウェブアプリケーションを作成するためのライブラリです。

## インストール

htmx をインストールするには、以下のコマンドを使用します。

```bash
npm install htmx
```

## 使い方

基本的な使い方については、公式ドキュメントを参照してください。

## サンプルコード

以下に、簡単なサンプルコードを示します。

```html
<button hx-get="/example" hx-target="#result">Click Me!</button>
<div id="result"></div>
```
